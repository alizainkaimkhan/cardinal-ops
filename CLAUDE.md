# CardinalOps

Multi-agent UofL student assistant. Next.js 15 (App Router, TypeScript, Tailwind) dashboard in `web/`, FastAPI backend in `api/`. Full architecture and milestones: `docs/spec.md` — read it before non-trivial changes.

## Commands
- `cd web && npm run dev` — frontend dev server
- `cd web && npm run build && npm run lint` — must pass before any commit
- `cd api && uv run uvicorn main:app --reload` — backend dev server
- `cd api && uv run pytest` — backend tests

## Conventions
- TypeScript strict mode; no `any` without a comment justifying it
- Tailwind utility classes only; no separate CSS files
- Server components by default; `"use client"` only where interaction requires it
- API responses use the envelope `{ data, error, trace_id }` — defined in `api/schemas.py`
- Every agent/tool/model call emits a trace event; no silent steps
- Conventional Commits: `feat:`, `fix:`, `docs:`, `chore:`, `refactor:`, `test:`
- Feature-branch workflow: no direct commits to `main`; every change lands via PR

## Don't
- Don't add dependencies without asking first
- Don't touch `data/corpus/` — generated by the ingest script
- Don't put secrets in code or commits; env vars only (`.env` is git-ignored, `.env.example` documents required vars)
- Don't mark milestone checkboxes in `docs/spec.md` done — the human does that
